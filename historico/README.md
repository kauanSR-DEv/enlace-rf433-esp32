# Histórico

`v3-go-back-n/` é a versão anterior do firmware, com **Go-Back-N** no lugar do Selective Repeat (mesmo quadro, mesmo CRC-8, mesma camada física, ACK sem mapa de bits). Fica aqui só para a comparação do [simulador](../tests/README.md). `v4.1-tx/` é o transmissor da v4.1 (sem a espera após o ACK e sem o preâmbulo maior no início da rajada), usado nas baterias de 21/11 e 23/11. A versão entregue é a de `firmware/`.
